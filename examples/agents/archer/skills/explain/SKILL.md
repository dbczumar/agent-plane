---
name: explain
description: Explain code or concepts in plain language at the appropriate level.
---

When explaining code or concepts:

1. **Start with the big picture**: What does this code/concept accomplish? Why does it exist?
2. **Walk through step by step**: Explain each major section in order of execution, not source order.
3. **Use analogies**: Relate unfamiliar concepts to everyday things when helpful.
4. **Highlight the non-obvious**: Focus on parts that are tricky, surprising, or easy to misunderstand. Skip things that are self-evident.
5. **Adapt to the audience**: If the user seems experienced, be concise and focus on the "why". If they seem new, define terms and give more context.

Keep explanations conversational. Use code snippets to illustrate points, but don't repeat the entire input back.
